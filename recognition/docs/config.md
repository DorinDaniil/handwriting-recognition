# Конфиг генератора

На каждый сэмпл выбирается **язык** (`p_ru`), затем берётся отрывок реального текста
из папок. Иногда в строку вносятся ошибки (блок ошибок) — они попадают и в картинку, и в таргет.
Случайных глифов и салата из слов больше нет (встроенный словарь — только аварийный фолбэк при пустых папках).

## CorpusConfig

| Параметр | По умолчанию | Описание |
|---|---|---|
| `ru_text_dirs` | `()` | папки с русскими `.txt` (реальный текст) |
| `en_text_dirs` | `()` | папки с английскими `.txt` |
| `ru_text_weights` | `()` | веса ru-папок (длина == `ru_text_dirs`): из какой брать чаще; `()` = по числу файлов |
| `en_text_weights` | `()` | то же для английских папок |
| `glob` | `"*.txt"` | маска файлов в этих папках |
| `cache_dir` | `None` | кэш-список найденных файлов; `None` → системный temp; удалить манифест = пересканировать |
| `p_ru` | `0.5` | доля русских строк (остальное — английские) |
| `len_chars` | `(8, 50)` | длина строки в символах (от..до), равномерно; задаёт и размер картинки (при curriculum верх растёт со `step`) |
| `p_hyphenate` | `0.15` | доля строк, оборванных на середине слова с переносом `-` |
| `lowercase_prob` | `0.0` | вероятность привести строку к нижнему регистру |

### Блок ошибок (имитация ошибок в почерке; ошибка идёт и в таргет)

| Параметр | По умолчанию | Описание |
|---|---|---|
| `p_text_error` | `0.25` | вероятность, что строка вообще получит ошибки |
| `p_letter_sub` | `0.06` | вероятность на букву заменить её на похожую (RU: о↔а, е↔и…; EN: a↔e, s↔z…) |
| `p_drop_punct` | `0.35` | вероятность убрать один знак пунктуации |
| `p_typo` | `0.12` | вероятность сдвоить или пропустить одну букву |
