# Разметчик строк (`annotate.py`)

Локальный веб-инструмент для разметки **полигонов текстовых строк** на рукописных страницах. Транскрипция каждой строки подгружается из
соседнего файла `<image>.txt`, поэтому задача разметчика — обвести строки и при
необходимости поправить текст. Результат сохраняется в формате, который напрямую идёт в
обучение как детектора, так и распознавателя.

## Требования

- Python 3.9+
- `pip install flask`

## Запуск

```bash
python annotate.py --root annotated_data        # папка с картинками (+ .txt рядом)
```

Затем откройте в браузере **http://127.0.0.1:5000**.

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `--root` | `annotated_data` | Папка датасета (рекурсивно ищутся картинки с соседним `.txt`) |
| `--host` | `127.0.0.1` | Адрес привязки (`0.0.0.0` — открыть доступ по сети) |
| `--port` | `5000` | Порт |

Интерфейс: слева — список страниц (✓ = уже размечена), по центру — холст со страницей,
справа — панель строк (в порядке чтения).

## Порядок разметки

1. Активная строка подсвечена в правой панели. Кликните её **4 угла** на изображении.
2. После 4-го клика полигон замыкается, активной становится **следующая** строка — так вы
   размечаете страницу сверху вниз, строку за строкой.
3. Любой угол можно перетащить мышью для корректировки.

Прогресс и число боксов отображаются в верхней панели; переход между страницами
автоматически сохраняет текущую.

## Горячие клавиши и мышь

| Действие | Результат |
|----------|-----------|
| Клик | Поставить угол активной строки |
| Перетащить угол | Сдвинуть точку |
| `z` / `Ctrl+Z` | Отменить последнюю точку (в т. ч. у только что закрытой строки) |
| `r` | Сбросить полигон активной строки (обвести заново) |
| `x` (или кнопка ✕) | Удалить строку |
| `a` | Добавить пустую строку |
| `Tab` / `Shift+Tab` | Следующая / предыдущая строка |
| `Alt+↑` / `Alt+↓` | Переместить строку вверх / вниз (также кнопки ▲▼ или перетаскивание за номер `#`) |
| Колесо мыши | Масштаб к курсору |
| Правая кнопка / `Space`+перетаскивание | Панорамирование |
| `f` | Вписать страницу в окно |
| `s` / `Ctrl+S` | Сохранить |
| `n` / `p` | Следующая / предыдущая картинка (с автосохранением) |
| `h` | Показать/скрыть подсказку поверх холста |

## Редактирование текста

- Текст в правой панели **редактируется на месте** — кликните строку и правьте.
- При сохранении текст записывается обратно в `<image>.txt` — одна строка на визуальную строку.
- При перемещении строки её **полигон, текст и номер** двигаются вместе, сохраняя
  соответствие «строка ↔ бокс».

## Что сохраняется

**Для каждой картинки — `<image>.json`** (полигоны в паре с текстом):

```json
{
  "image": "page_017.jpg",
  "width": 2480,
  "height": 3508,
  "lines": [
    {"order": 1, "polygon": [[x,y],[x,y],[x,y],[x,y]], "text": "..."}
  ]
}
```

**Для всего датасета — `<root>/labels.txt`** (формат PaddleOCR, пересобирается при каждом
сохранении; кнопка **Export labels.txt** пересобирает вручную):

```
<rel_path>\t[{"transcription": "...", "points": [[x,y],[x,y],[x,y],[x,y]], "score": 1.0}, ...]
```

Экспортируются только строки с полным 4-точечным полигоном. `labels.txt` — готовый вход для
обучения детектора DBNet++; пары `(полигон, текст)` из JSON служат таргетами и для
распознавателя строк.
